# Идеи: клиентский канал (поиск / фильтр без кнопок под каждым постом)

Канал остаётся **лентой объявлений**. Сотрудники по-прежнему публикуют через бота (отдельный сценарий, не убираем).

Ограничение Telegram: **внутри самой ленты канала** нельзя сделать полноценный интерактивный фильтр (город, тип и т.д.) как в приложении — подписчики не пишут в канал и не «жмут бота» в чате канала.

Ниже — **две рабочие идеи точки входа** «из канала дальше к фильтру», без кнопок под каждым постом.

---

## 1. Mini App (веб-приложение в Telegram)

- В **закрепе** или **описании канала** одна кнопка вроде **«Фильтр»** / **«Поиск»**.
- По нажатию открывается **Mini App** — интерфейс внутри клиента Telegram (не отдельный браузер сбоку).
- Там: фильтры (например город + категория), список объявлений, переход к **конкретному посту в канале** по ссылке.
- Нужны: **хостинг** страницы + **HTTPS** + регистрация URL у BotFather; бот остаётся точкой привязки Mini App.

**Плюсы:** ощущение «не вышел из Telegram», можно богатый UI.  
**Минусы:** не только `bot.py`, нужен фронт и бэкенд API.

---

## 2. Бот в личке (тот же или отдельный клиентский)

- В закрепе / описании **одна ссылка** на бота, например `https://t.me/ИМЯ_БОТА?start=filter` (то же работает с параметрами `client` или `search`).
- В коде бота: после `/start` пользователь выбирает **«Клиент»** или **«Сотрудник»**; клиентский сценарий — поиск по городу и категории с кнопками «открыть в канале».
- Клиент нажимает → открывается **личка с ботом** → пошаговый выбор фильтров → выдача карточек + кнопки **«Открыть в канале»** (ссылка на сообщение в канале).
- Сотрудники используют **того же бота**: отдельное меню (создание карточки) только для своих ID; клиентам — только поиск.

**Плюсы:** уже почти всё можно делать на Python + SQLite, без веба.  
**Минусы:** формально это другой «чат» (личка с ботом), не лента канала.

---

## Что зафиксировать в ТЗ для заказчика

| Вариант        | Пользователь видит                         |
|----------------|---------------------------------------------|
| Mini App       | Кнопка в канале → экран фильтра в Telegram |
| Бот            | Ссылка из канала → диалог с ботом         |

Можно **комбинировать**: в закрепе две кнопки — «Фильтр (Mini App)» и «Поиск в боте» — если позже решите поддерживать оба канала входа.
