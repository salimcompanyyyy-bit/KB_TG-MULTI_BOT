# Безопасность: токен Telegram-бота

Когда будешь заниматься этим вопросом — ориентируйся на этот файл.

## Зачем что-то менять

Сейчас токен бота может быть **записан прямо в `bot.py`**. Это **секретный ключ**: по нему Telegram считает процесс «владельцем» бота.

- У кого есть файл с токеном — тот может **управлять ботом** (от имени бота).
- Если файл **утёк** (скопировали, выложили, отправили) — имеет смысл **отозвать старый токен** и перейти на хранение секрета **вне кода**.

## Шаг 1 — перевыпуск токена (BotFather)

1. В Telegram открыть **@BotFather**.
2. Команда **`/mybots`** → выбрать своего бота.
3. Раздел про **API Token** → **Revoke** / отозвать текущий токен.
4. Скопировать **новый** токен (одна строка, длинная).

После отзыва **старый токен перестаёт работать** — бот с ним запускаться не будет, пока нигде не подставишь **новый**.

## Шаг 2 — хранить токен в переменной окружения (Windows)

Так токен **не лежит в `bot.py`** и не попадает в копии кода так же легко.

1. **Пуск** → поиск: **«переменные среды»** → **«Изменение системных переменных среды»**.
2. Кнопка **«Переменные среды…»**.
3. В блоке **«Переменные среды пользователя …»** → **«Создать…»**.
4. **Имя переменной:** `BOT_TOKEN`  
   **Значение:** вставить **новый** токен из BotFather (целиком, одной строкой).
5. Сохранить. Закрыть все окна PowerShell/CMD/IDE, где запускаешь бота, и открыть **заново** — иначе процесс не увидит новую переменную.

## Шаг 3 — правка `bot.py` (когда дойдёшь руками)

Идея:

- Убрать строку с токеном из файла.
- В начале после `import os` задать что-то вроде:

```python
import os

API_TOKEN = os.environ["BOT_TOKEN"]
```

Если переменной нет — при запуске будет ошибка `KeyError`; значит, не задана `BOT_TOKEN` или не перезапущено окно терминала.

Опционально (удобнее сообщение об ошибке):

```python
API_TOKEN = os.environ.get("BOT_TOKEN", "").strip()
if not API_TOKEN:
    raise SystemExit("Задайте переменную окружения BOT_TOKEN (токен от @BotFather).")
```

## Git и секреты

- Не коммитить файлы с токеном и не коммитить `.env` с реальным токеном.
- Если появится `.env` — добавить его в **`.gitignore`** в корне репозитория бота.
