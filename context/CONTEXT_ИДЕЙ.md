## Клиентский вход из канала в поиск

Канал остается лентой объявлений. Полноценный интерактивный фильтр внутри самой ленты сделать нельзя, поэтому точка входа в поиск остается через текущий сценарий бота в личке.

### Принятое решение

- Mini App исключен из плана.
- Развиваем текущую реализацию поиска в одном боте.
- Точка входа: ссылка из канала на бота с параметром `start` (`filter`, `client`, `search`).
- Поиск остается на текущем стеке Python + SQLite.
