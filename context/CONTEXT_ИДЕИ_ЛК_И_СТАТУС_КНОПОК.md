# Идеи: личный кабинет и статус кнопок

Документ для бэклога продукта. Код: `bot.py`.

---

## Нумерация объявлений (сделано)

- **Номер объявления** = поле `id` в таблице `posts` (автоинкремент SQLite).
- Перед отправкой в канал создаётся запись в БД, в текст карточки в канале добавляется строка вида `🔢 Объявление №{id}`.
- После успешной отправки в `posts` проставляется `channel_message_id`.
- Если отправка в канал упала с ошибкой, черновик без `channel_message_id` удаляется.
- В клиентском поиске в списке и на кнопках-ссылках отображается **№**.
- В превью перед публикацией номер ещё неизвестен (показывается пояснение, что № будет после публикации).

Идеи на потом: отдельный «человеческий» счётчик без дыр (если удаляют черновики), префикс года (`2026-0042`) — только если заказчик попросит.

## Личный кабинет сотрудника — что проработать

Сейчас вход: кнопка **«👤 Личный кабинет»** → профиль (имя/телефон из `users`) и две inline-кнопки.

### Цели

1. **Профиль** — создание/просмотр; **«Изменить данные»** — меню: отдельно **ФИО**, **телефон**, **Telegram** (плюс «Отмена»).
2. **«Мои публикации»** — выборка из **`posts`** с **№**, кратким описанием и кнопками **«Открыть №…»** в канал (если есть `channel_message_id`).
3. **Telegram в профиле** — колонка `users.tg_username`, кнопка **«Указать Telegram»** (@username или ссылка `t.me/…`), снятие значения символом `-`.
4. **Предпросмотр карточки** — в личном кабинете кнопка **«Предпросмотр карточки»**: шаблонный объект + внизу ваши контактные данные так же, как уйдёт в пост канала (имя, телефон, ссылка на Telegram).
5. Опционально на потом: счётчик публикаций за месяц, черновики.

### Технически

- Карточка в канале: номер в подписи + **экранирование HTML** в `build_card_text`, чтобы спецсимволы в адресе/имени не «ломали» подпись (из‑за этого текст поста мог не отображаться целиком).
- Старые посты в канале, опубликованные **до** этих правок, в ленту не переписываются — у них подпись как была.
- В тексте объявления в канале блок контактов **в две строки**: первая — **ФИО**, вторая — **телефон** и **@username** (если указаны в профиле).

## Кнопки и пункты меню: что не доведено до конца

| Место | Подпись / callback | Поведение |
|--------|-------------------|-----------|
| Личный кабинет | **📝 Изменить данные** (`edit_p`) | **Сделано**: FSM имя → телефон, кнопка «Отмена». |
| Личный кабинет | **📋 Мои публикации** (`my_posts`) | **Сделано**: последние записи из `posts` с № и ссылками в канал. |
| Админка → Статистика | **📊 Статистика** (`adm_stats`) | Заглушка: «функция в разработке». |
| Админка → Статистика | **📤 Экспорт stats** (`export_stats`) | Заглушка. |
| Админка → Логи | **📋 Логи** (`adm_logs`) | Заглушка. |
| Админка → Логи | **📤 Экспорт logs** (`export_logs`) | Заглушка. |
| Админка → Сотрудники | **👥 Сотрудники** (`adm_staff_list`) | Только alert «в разработке». |
| Админка → Сотрудники | **📥 Заявки доступа** (`adm_access_requests`) | Только alert «в разработке». |
| Админка → Служебное | **🔎 Поиск публикаций** (`adm_search_posts`) | Только alert «в разработке». |

Остальные кнопки админки вроде **DB check**, **Импорт CSV**, **Добавить ID**, **Тех. перерыв** — обрабатываются.
