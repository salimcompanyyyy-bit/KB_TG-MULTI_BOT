# Как запустить бота — пошагово (Windows)

**Шпаргалка (копипаста команд):** [CONTEXT_ШПАРГАЛКА_ЗАПУСК.md](CONTEXT_ШПАРГАЛКА_ЗАПУСК.md)

`C:\Users\Kawa\OneDrive\Рабочий стол\Кб\KB_TG_бот_по_недвижке`

## Шаг 1. Проверить Python

1. Открой **PowerShell** или **«Терминал»** / **cmd**.
2. Выполни:

```powershell
python --version
```

Должно показать что-то вроде `Python 3.10` или новее (3.11, 3.12, 3.14).

- Если пишет «не найдено» — установи Python с https://www.python.org/downloads/  
  При установке включи галочку **«Add python.exe to PATH»**.

---

## Шаг 2. Перейти в папку бота

В том же окне PowerShell:

```powershell
cd "C:\Users\Kawa\OneDrive\Рабочий стол\Кб\KB_TG_бот_по_недвижке"
```

Проверка, что ты в нужном месте:

```powershell
dir bot.py
```

Должен показать файл `bot.py`.

---

## Шаг 3. Установить библиотеку aiogram

Один раз (или после смены компьютера):

```powershell
python -m pip install -U pip
python -m pip install -U aiogram
```

Дождись окончания без красных ошибок.

---

## Шаг 4. Запустить бота

```powershell
python bot.py
```

**Нормально**, если в консоли идут строки логов (INFO) и окно **не закрывается** — бот в режиме **long polling** и ждёт сообщения в Telegram.

- Остановить бота: в этом же окне нажми **`Ctrl+C`**.

---

## Шаг 5. Проверить в Telegram

1. Открой своего бота в Telegram (по имени, которое давал в BotFather).
2. Нажми **«Старт»** / **Start** или отправь `/start`.
3. Если бот отвечает — всё работает.

Если не отвечает:

- Убедись, что окно с `python bot.py` **всё ещё открыто** и не упало с ошибкой.
- Проверь интернет.
- Если менял токен — в `bot.py` или в `BOT_TOKEN` должен быть **актуальный** токен (см. `context/CONTEXT_SECURITY.md`).

---

## Частые проблемы

| Симптом | Что сделать |
|--------|-------------|
| `ModuleNotFoundError: aiogram` | Повтори шаг 3 (`pip install aiogram`). |
| `python` не находится | Переустанови Python с PATH или попробуй `py bot.py` вместо `python bot.py`. |
| Окно сразу закрывается | Запускай из PowerShell, а не двойным щелчком по `bot.py` — так увидишь текст ошибки. |
| Два запуска с одним токеном | Закрой второй процесс; один токен — один активный polling. |

---

## Чтобы бот работал, пока ПК включён

Пока запуск **вручную**: окно PowerShell с `python bot.py` должно оставаться открытым.

Чтобы не зависеть от окна (позже):

- **Планирователь заданий Windows** — запуск `python` с аргументом `bot.py` и рабочей папкой = папка бота.
- Или служба / NSSM — отдельная настройка.
